# 🏠 House Price Prediction

This is a basic machine learning project that predicts house prices based on:

- Square footage
- Number of bedrooms
- Number of bathrooms

The model is trained using linear regression and the dataset is from Kaggle.

## 🔧 Technologies Used

- Python
- Scikit-learn
- Pandas
- Google Colab
- Gradio (for the web interface)

## 🚀 How to Run

### On Google Colab
1. Open the `main.ipynb` notebook.
2. Run all cells.
3. Use the interface to test predictions.

### Locally
```bash
pip install -r requirements.txt
python app.py

## 📥 How to Get the Dataset

1. Go to the Kaggle competition page:  
   https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data
2. Download the `train.csv` file
3. Place it in the same folder as your notebook or script
